# Design history

These are the design notes Rebind was built from, kept as a record. They are not documentation of
the program as it is: each was written before the work it describes, and several were overtaken.
In particular the first, `2026-07-22-rebind-design.md`, proposes rebuilding a document from
scratch; that approach was dropped a week later in favour of keeping each page as it is and adding
only what it lacks, which is what Rebind does.

For how Rebind works now, see [how-it-works.md](../how-it-works.md). For the decisions that still
stand, see [decisions](../decisions/).
